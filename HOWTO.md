# RESx — How to use

RESx is a tool for exploring a RES (Reference Energy System) built from a VEDA VDT file.

The basic workflow is:

1. build the RES from a VDT file;
2. obtain the complete RES as a GraphML file;
3. use RESx subcommands to extract parts of the RES;
4. open the resulting GraphML files in [yEd](https://www.yworks.com/products/yed) to visualize the topology.

The `demo/` directory contains an example VDT file and an example yEd Properties Mapper configuration file.

## 1. Go to the demo directory

From the root of the RESx repository:

```bash
cd demo
```

The `demo/` directory contains all the files required for this example.

## 2. Build the RES

Initialize RESx from the example VDT file:

```bash
resx init RES.vdt
```

This creates the following GraphML file:

```text
current-res.graphml
```

This file contains the complete RES and can be opened directly in yEd.

## 3. Explore the RES

RESx provides several commands to extract specific parts of the RES:

```bash
resx parents NODE
```

List the parent nodes of `NODE`.

```bash
resx children NODE
```

List the child nodes of `NODE`.

```bash
resx path SOURCE TARGET
```

Find the shortest path between `SOURCE` and `TARGET`.

```bash
resx neighbours NODE ...
```

Extract the neighbours of one or more nodes at specified depths.

```bash
resx sector ...
```

Extract the neighbourhood of nodes matching a specified sector.

For a detailed description of each command:

```bash
resx parents --help
resx children --help
resx path --help
resx neighbours --help
resx sector --help
```

The commands produce GraphML files containing the selected subgraphs.

## 4. Open a GraphML file in yEd

Open [yEd](https://www.yworks.com/products/yed) and select:

**File → Open**

Then open `current-res.graphml` or one of the GraphML files generated by the RESx subcommands.

## 5. Import the Properties Mapper configuration

The `demo/` directory contains an example yEd Properties Mapper configuration.

In yEd:

1. Open **Edit → Properties Mapper**.
2. In the Properties Mapper window, click the **green downward arrow**.
3. Import the example configuration file from the `demo/` directory.

The configuration sets the visual properties of the nodes and edges.

## 6. Apply a layout

Open the **Layout** menu in yEd and select the layout algorithm of your choice.

You can experiment with different layouts to obtain a clear representation of the RES topology.

## Command overview

```text
Usage: resx [OPTIONS] COMMAND [ARGS]...

  RES Explorer: build RES from VDT file, extract subgraphs.

Commands:
  init        Initialize RES from vdt_file argument.
  parents     List parents nodes of argument NODE.
  children    List children nodes of argument NODE.
  path        Graph shortest path between SOURCE and TARGET.
  neighbours  Graph neighbours at depths UP,DOWN of a list of nodes.
  sector      Graph all neighbours at depths=(1,1) of nodes matching...

```

Run:

```bash
resx --help
```

for the complete list of commands and options.
